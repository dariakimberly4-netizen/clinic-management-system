# Clinic Management System

Mobile-first Clinic Command Center for appointments, patient queue, doctors, consultations, prescriptions, pharmacy, inventory, billing, patient records, diagnostics, referrals and reports.

## Demo login
Select any role and use PIN: `1234`.

## Run
Open `index.html` or enable GitHub Pages from **Settings → Pages → Deploy from a branch → main / root**.

This first working build persists data in the browser using localStorage. For real clinical deployment, replace demo authentication/storage with a secured backend, access controls, audit logs, backups, encryption, and applicable privacy/compliance safeguards. Do not store real patient health information in this public demo repository.
